Flight search

Set the search, check the call count, run it. Results come from SerpApi's Google Flights endpoint, run by a GitHub Actions job.

Route and dates

Up to 10 airport codes per box, comma separated. An empty "before" date means the same day as "after", so two single dates is one search.

Passengers and price

Max price, flight time and stopover are sent to the API and checked again on the results. Whether the price covers all passengers is not confirmed yet.

Airlines and cabin

Used when Airlines is "Only these" or "Exclude these". Type 2-letter airline codes (SQ is Singapore Airlines, QF is Qantas) and tick any alliances. The API applies these filters. The results table can't re-check them, so look at the flights column. The cabin is shown on each flight.

Time windows (hour of day, 0 to 23)
Outbound departs from to arrives from to
Return departs from to arrives from to

Fill one box or both. An empty "from" means from midnight, and an empty "to" means until 11:59 pm. Each number is the start of an hour and the "to" hour is included: departs from 7 means after 7:00 am, and arrives to 0 means before 1:00 am. If "from" is later than "to" the window crosses midnight: arrives from 6 to 0 means 6:00 am through 12:59 am the next morning. Outbound windows that cross midnight are checked on the results here, not by the API. Return windows are applied by the API only, and can't cross midnight yet; return flights are not shown below.
